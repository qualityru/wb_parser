# wb_parser

Скрипт собирает каталог товаров Wildberries по запросу `пальто из натуральной шерсти` и сохраняет результат в Excel (`.xlsx`).

В выгрузку входят:
- ссылка на товар
- артикул
- название
- цена
- описание
- ссылки на изображения через запятую
- все характеристики с сохранением структуры
- название селлера
- ссылка на селлера
- размеры товара через запятую
- остатки по товару
- рейтинг
- количество отзывов

После запуска создаются 2 файла:
- `wb_catalog.xlsx` - полный каталог
- `wb_catalog_filtered.xlsx` - товары с рейтингом от 4.5, ценой до 10 000 и страной производства `Россия`

## Как запустить

Нужен Python 3.10+.

1. Установите зависимость:

```bash
pip install requests
```

2. Запустите скрипт:

```bash
python main.py
```

3. Дождитесь окончания работы. Готовые `.xlsx` файлы появятся в текущей папке проекта.
